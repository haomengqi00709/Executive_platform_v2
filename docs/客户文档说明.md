## 整体格式特征（所有 10 份共享）

- **标题页元数据**：title + subtitle (tier 名) + Effective Date / Last Updated / Version
- **自动目录**：pandoc 生成的 2 级 TOC（Heading 1 + Heading 2）
- **结尾免责声明**：固定一段 "beta-stage operational document, 未经律师 review, 商用前应过律师" 的诚实声明
- **正规法律表述**：
  - 定义术语用 quotation marks + bold（如 **"Account"** means ...）
  - 责任 / Disclaimer 章节用全大写（业界惯例显示重要性）
  - 时长写两种格式（"thirty (30) days" 数字 + 拼写并存）
  - 引用其他章节用 "§N" 或 "Section N"
- **占位符（红色字体留给你填）**：
  - `[COMPANY NAME]` — 公司名
  - `[STREET ADDRESS]` / `[CITY...]` / `[COUNTRY]` — 公司地址
  - `[PRIVACY@COMPANY.COM]` / `[LEGAL@COMPANY.COM]` — 邮箱
  - `[WWW.COMPANY.COM/PRIVACY]` — 网站
  - `[DATE]` — 生效日 / 更新日
  - `[JURISDICTION]` — 司法管辖（Terms of Service）
